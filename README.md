# Finanças Railana — Sistema de Produtividade

Aplicativo web em React + TypeScript para gestão de produtividade com:

- autenticação (cadastro/login/logout) com dados isolados por usuário;
- dashboard com resumo diário e indicadores;
- tarefas (prioridade, status, checklist, favoritos, filtros e recorrência);
- regra de recorrência com **Preservar domingos** (segunda ou sábado);
- visões: Hoje, Todas, Favoritas, Atrasadas e Concluídas;
- pastas, rotinas, projetos e notas;
- calendário mensal interativo;
- assistente IA para sugerir plano e criar tarefas;
- busca global (Ctrl+K), atalhos, notificações;
- backup JSON (exportar/importar com confirmação);
- personalização de aparência (tema, densidade, fonte e cor principal);
- dados de demonstração no primeiro acesso.

## Executar

```bash
npm install
npm run dev
```

## Validar

```bash
npm run lint
npm run build
```
